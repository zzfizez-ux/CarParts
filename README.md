# CarParts

AI-assisted vehicle parts finder concept.

This front-end prototype makes it simple to identify a vehicle, describe the part needed, compare best-value/premium/OEM options, and understand when compatibility still needs confirmation.

The UI uses mock product data. A production build should connect the interface to vehicle identification, fitment/OEM databases, inventory, pricing and supplier APIs.

Open index.html locally or enable GitHub Pages for the main branch.
